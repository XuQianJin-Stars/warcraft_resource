# 技能图标 Prompt（64×64px）

> **用途**：技能选择界面、技能树界面、英雄选中面板
> **工具**：GPT-4o 生成
> **风格**：卡通化，色彩鲜明，与技能效果对应
> **输出格式**：PNG（透明背景），64×64px
> **需要状态**：解锁（彩色）/ 锁定（灰色，可程序处理）

---

## 通用 Prompt 模板（GPT-4o）

```
请生成一个64×64像素的游戏技能图标。
风格：Q版卡通，圆角方形，粗黑色描边，高饱和度配色。
技能：{技能名称}，{视觉描述}。
背景为深色渐变，图标内容居中，清晰可辨。
PNG透明背景。
```

1. 所有技能图标使用 **GPT-4o** 生成

3. 每个图标的主色调要与技能效果对应
4. 锁定状态（灰色版本）由程序处理，不需要单独生成
5. 总计 **64个技能图标**（16英雄 × 4技能）
