# 商店物品图标 Prompt（64×64px）

> **用途**：商店界面和物品栏中的物品图标
> **工具**：GPT-4o 生成
> **风格**：卡通化，色彩鲜明，粗描边
> **输出格式**：PNG（透明背景），64×64px

---

## 通用 Prompt 模板（GPT-4o）

```
请生成一个64×64像素的游戏物品图标。
风格：Q版卡通，粗黑色描边，高饱和度配色。
物品：{物品名称}，{外观描述}。
背景透明，适合作为游戏商店物品图标。
```
