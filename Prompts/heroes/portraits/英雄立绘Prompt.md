# 英雄全身立绘 Prompt（512×768px）

> **用途**：英雄图鉴界面右侧详情展示
> **工具**：DeepSeek 生成 Prompt → Midjourney 生成图片
> **风格**：Q版卡通，2:1~3:1头身比，粗黑色描边，高饱和度配色，白色背景
> **输出格式**：PNG（透明背景），512×768px

---

## 通用 Prompt 模板

```
Q版卡通风格，魔兽争霸3 {英雄名称}，2:1头身比，
粗黑色描边，高饱和度配色，{阵营主题色}为主色调，
{具体外观描述}，白色背景，游戏角色设计，
全身像，正面视角，可爱夸张的表情，
chibi style, game character design, full body,
white background, thick black outline, vibrant colors
--ar 2:3 --style raw --v 6
```

## 📋 生成注意事项

1. **先生成大法师作为风格基准**，确认满意后再批量生成其他英雄
2. 如果 Midjourney 生成的图片有白色背景但不够干净，可用 remove.bg 去除背景
3. 生成后需要统一调整为 512×768px 尺寸
4. 建议每个英雄生成 4 张变体，选取最佳版本
5. 如果某个英雄效果不理想，可以用 DeepSeek 优化 Prompt 后重新生成
