# 英雄头像图标 Prompt（128×128px）

> **用途**：卡牌栏（英雄卡牌头像）、选中面板（英雄信息）、技能选择界面（英雄选择区）、技能树界面（顶部英雄展示）、暂停界面（已部署英雄 + 技能说明区）、失败界面（英雄展示）、结算界面（英雄展示 + 最强英雄）
> **工具**：GPT-4o 生成（适合小尺寸图标）
> **风格**：圆形裁切，卡通Q版，表情生动，粗黑描边
> **输出格式**：PNG（透明背景），128×128px

---

## 通用 Prompt 模板（GPT-4o）

```
请生成一个128×128像素的游戏角色头像图标。
风格：Q版卡通，圆形构图，粗黑色描边，高饱和度配色。
角色：魔兽争霸3的{英雄名称}，{简要外观描述}。
要求：只显示头部和肩部，表情生动夸张，背景透明，
适合作为游戏UI中的小图标使用。
```
