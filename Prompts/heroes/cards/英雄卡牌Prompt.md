# 英雄卡牌美术 Prompt（100×140px）

> **用途**：底部英雄卡牌栏，战斗中选择和放置英雄
> **工具**：GPT-4o 生成
> **风格**：卡通风格卡牌，包含英雄半身像、名称区、费用区
> **输出格式**：PNG（透明背景），100×140px

---

## 通用 Prompt 模板（GPT-4o）

```
请生成一张100×140像素的游戏英雄卡牌。
风格：Q版卡通，圆角矩形卡牌，{品质边框色}边框。
内容：
- 上方2/3区域：{英雄名称}的Q版半身像，{简要外观描述}
- 下方1/3区域：深色底板，显示英雄名称和金币费用
整体风格统一，色彩鲜明，适合手机游戏UI。
```
