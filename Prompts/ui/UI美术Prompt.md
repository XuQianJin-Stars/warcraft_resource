## 📋 生成注意事项

1. 所有UI素材使用 **GPT-4o** 生成，适合精确控制尺寸和布局
2. 按钮需要提供 **正常/按下** 两种状态（按下状态可程序处理变暗）
3. 所有UI元素保持 **统一的卡通风格** 和 **圆角设计**
4. 颜色参考项目配色方案：金色#FFD700、深蓝#1A237E、绿色#4CAF50、红色#F44336
5. 文字区域留空由程序动态添加，支持多语言
6. 半透明遮罩层由程序生成，不需要单独制作
