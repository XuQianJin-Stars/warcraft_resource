# 伤害数字字体 Prompt

> **用途**：战斗中浮动显示的伤害/治疗/金币数字
> **工具**：GPT-4o 生成
> **风格**：卡通数字字体，粗描边，色彩鲜明
> **输出格式**：PNG（透明背景），每个数字约 32×40px

---

## 通用说明

需要生成 0-9 共10个数字 + 特殊符号（+、-、!），共5种颜色版本。
每种颜色的数字组成一个 sprite sheet。

---

## 📋 生成注意事项

1. 所有数字字体使用 **GPT-4o** 生成
2. 每种颜色的数字风格要统一，大小一致
3. 暴击数字要比普通数字 **大约25%**，更加醒目
4. 数字需要有 **粗描边**，确保在各种背景上都清晰可见
5. 生成后需要手动切割为单个数字，或在程序中按固定宽度读取
6. 如果 GPT-4o 生成的数字不够整齐，可以考虑使用卡通字体库替代
